# Testing Patterns

**Analysis Date:** 2026-11-07

## Test Framework

**Runner:**
- `flutter_test` (Flutter SDK built-in test runner) declared in `pubspec.yaml`
- `package:test` (v1.25.6) in `packages/byte_me/pubspec.yaml`

**Assertion Library:**
- `package:flutter_test/flutter_test.dart` assertions (`expect()`, `findsOneWidget`, `throwsA()`)

**Run Commands:**
```bash
flutter test                         # Run all tests in the project
flutter test test/unit/sample_test.dart # Run single test file
flutter test --coverage              # Generate coverage report into coverage/lcov.info
genhtml coverage/lcov.info -o coverage/html # Generate HTML coverage report (lcov required)
```

## Test File Organization

**Location:**
- Root `test/` directory is currently **absent** from the main application codebase.
- Sub-package unit tests are housed within their respective sub-packages:
  - `packages/flutter_web_auth/flutter_web_auth_2/test/flutter_web_auth_2_test.dart`
  - `packages/flutter_web_auth/flutter_web_auth_2_platform_interface/test/flutter_web_auth_platform_interface_test.dart`
  - `packages/anymex_extension_bridge/linux/test/` (C++ unit tests)
  - `packages/anymex_extension_bridge/windows/test/` (C++ unit tests)

**Naming:**
- Standard Dart test naming convention: `*_test.dart` mirroring source file names under a parallel directory structure.

## Test Structure

**Suite Organization:**
```dart
import 'package:flutter_test/flutter_test.dart';

void main() {
  group('TitleMatcher', () {
    setUp(() {
      // Setup test fixtures or instances
    });

    tearDown(() {
      // Clean up resources, database connections
    });

    test('normalizes anime title strings accurately', () {
      // Arrange
      const rawTitle = 'Attack on Titan: Final Season [Batch]';

      // Act
      final result = normalizeTitle(rawTitle);

      // Assert
      expect(result, equals('Attack on Titan Final Season'));
    });
  });
}
```

**Patterns:**
- `setUp()`: Re-initializes state or in-memory database schemas before each test case
- `tearDown()`: Cleans up temp directories and cancels active streams
- `expect(actual, matcher)`: Standard Dart matcher syntax

## Mocking

**Framework:**
- `mockito` / manual mock classes implementing interfaces or Riverpod provider overrides

**Patterns:**
- Riverpod container overrides for test isolation:
  ```dart
  final container = ProviderContainer(
    overrides: [
      databaseProvider.overrideWithValue(mockIsar),
      sharedPreferencesProvider.overrideWithValue(mockPrefs),
    ],
  );
  addTearDown(container.dispose);
  ```

**What to Mock:**
- Remote network HTTP clients (`rhttp`, `http.Client`)
- Disk I/O and secure OS storage (`FlutterSecureStorage`)
- Hardware sensors and native window manager APIs

**What NOT to Mock:**
- Domain entity business logic and parser functions
- Pure utility formatters (`lib/core/utils/formatting.dart`)
- Value objects and immutable state data structures

## Fixtures and Factories

**Test Data:**
- Factory constructors on domain entities or static JSON fixtures:
  ```dart
  UnifiedMedia createTestMedia({String id = '1', String title = 'Test Anime'}) {
    return UnifiedMedia(
      id: id,
      title: title,
      mediaType: MediaType.ANIME,
    );
  }
  ```

**Location:**
- Proposed location: `test/fixtures/` for JSON payloads and `test/helpers/` for test builders

## Coverage

**Requirements:**
- Currently **None enforced** in CI pipeline. Coverage reports are not generated by default in `.github/workflows/`.

**View Coverage:**
```bash
flutter test --coverage
# HTML view requires lcov:
genhtml coverage/lcov.info -o coverage/html
xdg-open coverage/html/index.html
```

## Test Types

**Unit Tests:**
- Scope: Parsing logic (ASS/SRT subtitle parsers, title matcher), URL decoding, stream URL proxy logic, cache TTL calculation.
- Implementation status: Needed for core application utilities and repository logic.

**Widget Tests:**
- Scope: Verification of custom UI components (`MediaCard`, `PlayerControlsOverlay`, `CustomSubtitleOverlay`) in headless test environment.
- Implementation status: None currently present in root codebase.

**Integration Tests:**
- Scope: Full end-to-end flows using `package:integration_test` (e.g. searching anime -> launching player -> recording progress).
- Implementation status: Not configured.

## Common Patterns

**Async Testing:**
```dart
test('fetches and caches remote config', () async {
  final service = RemoteConfigService(mockPrefs);
  await service.fetchRemoteConfig();
  expect(service.config, isNotNull);
});
```

**Error Testing:**
```dart
test('throws exception on invalid stream URI', () {
  expect(
    () => StreamServer.validateUrl('invalid://url'),
    throwsA(isA<FormatException>()),
  );
});
```
